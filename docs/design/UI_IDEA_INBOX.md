# DailyProof UI Idea Inbox

> Put this file in your repo as `docs/UI_IDEA_INBOX.md`.
> Use it for spontaneous ideas so they do not disappear into chat history.

## How to use it

When an idea hits you, capture it quickly. Do **not** immediately change the product.

Use this template:

```text
Date:
Idea:
Screen/component:
Problem it solves:
What should the user feel?
Priority: Low / Medium / High
Target: P3 / Final polish / V2
Decision: Unreviewed / Keep / Reject / Defer
Notes:
```

## Triage rules

At the end of a design session, move each reviewed idea into one of these outcomes:

**Keep** — add it to the Master Plan or Figma spec.  
**Reject** — document why so it is not repeatedly reconsidered.  
**Defer** — useful, but belongs in V2 or later.  
**Experiment** — prototype before committing.

Do not allow the inbox itself to become the product roadmap.
